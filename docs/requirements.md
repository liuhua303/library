# 功能需求

状态：当前规范；源码预备版本 0.4.0-dev.1。已有历史产物为 Windows 0.3.3 和 Mac 0.4.0-dev.0 试用包。更新日期：2026-11-28。

本文统一维护当前功能和使用边界。用户已确认首版阅读功能、后续书架与书签、六主题、沉浸阅读、M 系列 Mac 目标，以及本轮单词本跟随主题且清晰可读的要求；原来未单独确认的默认规则单列为实现基线，继续保留调整空间。实现与验证分别记录，本轮结果见 [0.4.0-dev.1 验证报告](./verification/0.4.0-dev.1.md)，上一版 Mac 云端结果见 [0.4.0-dev.0 历史记录](./verification/0.4.0-dev.0.md)，原始讨论见 [首版归档](./archive/initial-requirements.md)。

## 已确认的目标与范围

面向有一定英语基础、阅读英文书籍时需要查词和理解句子的个人用户。核心目标是减少查看释义对阅读的打断：先收录，后台解析，由用户主动查看。

- 提供可安装并从桌面打开的本地软件，保留 Windows x64，并新增 Apple Silicon Mac arm64 目标；阅读格式仍只支持 EPUB。
- 采用逐页阅读，支持目录和书签跳转、字号及主题调整，以及按内容位置续读。
- 每次启动先显示书架，封面使用 EPUB 自带图片并呈现书本质感；封面左下角显示该书阅读进度。点击书籍进入上次保存的位置，未读书从开头进入。
- 每本书拥有独立单词本；书籍、位置、收录语境、解析任务、书签和阅读设置保存在本机。
- 默认保留白底阅读，同时提供六种阅读主题；主题、字号按书保存。完整视觉规则见 [界面规范](./ui-design.md)。
- 允许将收录词句及必要的附近原文发送给用户提供密钥的 DeepSeek API。
- 约每天收录 100 条是讨论中的工作量估计，不是产品限额或已经测得的吞吐量。

## 本轮 Mac 支持范围与状态

- 用户明确选择只支持 M 系列 Mac（Apple Silicon、arm64），不制作 Intel x64 或 universal 通用包。
- 当前 Electron 45 的 Mac 运行目标为 macOS 13 或更新版本，依据 [Electron 移除 macOS 12 支持说明](https://www.electronjs.org/docs/latest/breaking-changes/#removed-macos-12-support)。
- 历史版本 0.4.0-dev.0 已在云端 Mac arm64 完成试用 DMG 构建及包内程序启动检查；试用包采用 ad-hoc 签名、未公证。正式 `release` 模式尚未运行，DMG 安装、Keychain 与真实阅读体验仍待人工验收。已有 Windows 历史安装包为 0.3.3，本轮新产物以新报告为准。
- Mac 实现约定采用系统应用与编辑菜单、Cmd 编辑/退出快捷键；关闭窗口先保存，程序保留在 Dock，可重新打开；真正退出时完成阅读位置保存。它们需经 Mac 实机验收，不以 Windows 结果替代。
- 提供 Mac 本机试用与正式分发两种构建入口；本机试用包采用 ad-hoc 签名且不公证，正式包要求 Developer ID 签名和公证。具体前置条件集中在 [开发说明](./development.md#mac-准备与打包)。
- 用户没有 Mac 环境，本轮新增手动 GitHub Actions 构建入口：完整源码进入仓库默认分支后，由维护者选择 `trial` 或 `release`，复用对应 Mac 构建命令，成功完成包内程序检查才提供 DMG artifact。工作流不自动发布 Release，也不把源码 ZIP 当作安装包；操作、下载权限与费用条件见 [开发说明](./development.md#通过-github-actions-构建)。
- 此前源码已上传到 [library 公开仓库](https://github.com/liuhua303/library)，0.4.0-dev.0 的 Mac 试用包云端构建和隔离启动检查已通过，属于上一版结果。云端自动化与真实 Mac 上的安装、Keychain 和阅读体验人工验收分别记录，不将构建通过改记为用户已逐项确认。

## 已确认的阅读与收录行为

| 操作 | 当前功能要求 |
| --- | --- |
| 单击未收录单词 | 立即收录并显示简单下划线，不等待模型、不弹出解析 |
| 拖选单词或句子 | 显示“复制 / 收录”菜单，选择收录后才入库 |
| 调整选区 | 首尾均可调整；翻页后保留选区，可通过“调整终点”继续选择新终点 |
| 点击阅读留白 | 有临时选区或选词菜单时先取消；有交互浮层时先关闭，本次不直接进入沉浸。无待处理操作时进入沉浸，不产生收录 |
| 识别完整短语 | 后台结合该处原文补全短语与含义，可靠定位后扩大原文下划线 |
| 点击已有标记 | 显示“查看 / 取消收录”菜单，由用户选择操作 |
| 查看已收录内容 | 打开右侧单词本，定位并展开对应词条及语境 |
| 返回原文 | 回到该次收录的位置，目标标记闪烁两次 |

右侧单词本通过阅读工具或 `J` 主动开关，采用覆盖式浮层。开关不改变正文容器尺寸、分页和当前阅读内容位置。收录或解析完成时不自动展开。键盘边界、工具和浮层细节见 [界面规范](./ui-design.md)。

## 已确认的沉浸阅读目标

- 点击阅读留白后隐藏鼠标指针和操作控件，仅保留正文、书名与页数；沉浸时书名居中。
- 底部左右翻页箭头永久移除，正常阅读与沉浸状态均不显示。
- 隐藏控件保留原布局位置，不因沉浸开关改变正文容器尺寸、重分页或重置当前内容位置。

本轮采用以下交互默认值：移动鼠标恢复指针和控件，`Esc` 退出沉浸，点击单词或开始拖选也恢复操作并继续原有收录流程。已有选区、选词菜单或工具、目录、主题等交互浮层时，点击留白先取消或关闭，本次不进入沉浸。左右方向键继续翻页，增加 `PageUp` / `PageDown` 与鼠标滚轮翻页；操作浮层及拖动选区手柄时不翻动背后书页。具体行为和检查范围见 [界面规范](./ui-design.md)。

## 已确认的导航、书签与阅读设置

- 阅读工具的导航入口显示“目录 · X%”，同步当前阅读进度；它与书架显示的是同一类按书保存的阅读进度，不把随字号变化的屏幕页码作为持久定位依据。
- 目录与书签放在同一个导航面板，通过“目录 / 书签”两个标签切换；不增加高亮标签。
- 阅读工具提供当前页书签入口。书签按书保存，列表支持跳转到对应内容位置及逐条删除，重启后保留。
- 阅读设置仅包含字号和主题：字号界面使用小 A / 大 A 按钮，不显示数值；仍在内部按原有范围和步长保存。
- 六种主题为 `original` 原色、`quiet` 静谧、`paper` 纸张、`bold` 醒目、`calm` 舒缓、`focus` 专注；默认原色保持白底。主题需协调正文、阅读工具、导航和单词本，深色主题下文字、选区、标记及状态仍清晰可读。
- 单词本使用与当前主题协调的不透明面板；正文、次要文案、原文标记和交互状态均清晰可读。开关继续采用覆盖方式，不重排正文，不增加模糊；具体色值与尺寸属于实现校准，不视为用户已逐项确认。
- API 密钥与模型配置只在书架设置中提供。阅读页和单词本不打开 API 设置；需要配置时仅简短引导返回书架，不因解析失败自动离开当前阅读位置。

## 已确认的单词本与解析内容

同一词在同一本书中多次收录时归为一个词条，保留各处原句和对应释义，最近收录时间随收录更新。不同书籍之间不合并词条，不用一处释义覆盖所有原句。

| 内容 | 解析要求 |
| --- | --- |
| 单词、短语 | 中文语境释义、英文解释、用法说明和例句；中文释义优先呈现 |
| 整句 | 提供中文翻译，不套用单词的完整解析结构 |

原句、章节、日期、多处语境、原文回跳、逐处取消及必要重试入口均保留；详细信息可以折叠展示。

## 已确认的数据与后台行为

- 离线时仍可阅读和收录，联网后处理未完成任务；真正退出程序暂停处理，下次启动恢复待处理任务。Mac 仅关闭窗口不视为退出程序。
- 显示待解析、解析中、等待联网、需要密钥、失败等必要状态，并提供重试或返回书架配置的简短引导，不用弹窗打断阅读。
- 每条语境通过一次完整的模型回答生成解析；技术失败允许重试，不额外增加自主词典查询、联网搜索或模型审查流程。
- 本机后台负责任务保存、上下文提取、请求执行、格式与原文定位校验，以及结果保存。
- 恢复任务可以重新发起中断的模型请求，不要求恢复生成到一半的内部状态。
- 本机密钥通过 Electron safeStorage 使用操作系统保护；Mac 对应 Keychain，授权与重启读取仍待实机验证。跨机器或跨系统使用需重新配置密钥，不将 Windows 加密文件视为可直接迁移的凭证。数据与技术实现见 [开发说明](./development.md)。

## 当前实现边界与默认规则

以下规则来自原稿的建议部分，已作为首版实现基线；这不表示用户已逐项确认。调整时直接修订本节，不必重开一份首版确认稿。

1. **书籍兼容**：面向正文未受 DRM 保护、可随字号重排的普通 EPUB。固定版式 EPUB 不在首版目标内，具体文件以实际试用为准；字体混淆与正文 DRM 应区分处理。
2. **跨页范围**：支持同章节内跨页选区；跨章节连续选区不在首版范围。
3. **取消一处**：只移除该处标记、语境及任务，其他位置保留；最后一处取消后词条消失，迟到的后台结果不得让已取消内容重新出现。
4. **词条归并**：同一词或完整短语忽略大小写归并，单词和短语分开；不做词形还原或同义词合并。
5. **短语定位**：只有完整短语能可靠匹配到该处真实原文时才扩展下划线；失败时保留原标记并允许重试。
6. **列表与例句**：按最近收录时间倒序展示，每处语境单独解析；单词或短语先提供一个例句。
7. **请求策略**：当前默认模型标识为 `deepseek-flash`，禁用思考模式；技术失败有限重试，密钥错误或余额不足等待用户处理。模型只在书架的 API 设置中修改。
8. **功能边界**：背词计划、测验、云同步、其他文件格式、移动端应用及跨设备同步不在本轮范围；不扩展搜索、分享、亮度、高亮标签或自定义布局。
9. **字号与主题**：字号内部范围为 14–34px，每次调整 2px；界面不显示字号数字。字号及主题按书保存，旧书没有主题记录时使用原色，不重置已有字号、位置或收录。

## 验收目标与待核对事项

以下是验收目标，实际完成程度以版本验证报告为准。

| 场景 | 验收目标 |
| --- | --- |
| 阅读与续读 | 实际书籍可导入、翻页、目录跳转及调整字号，重启后回到保存的内容位置 |
| Mac 平台 | 在 M 系列、macOS 13+ 实机核对窗口关闭/重开/真正退出、Cmd 菜单、密钥保存与重启读回；核对 arm64 包的安装、签名、公证及启动，不能沿用 Windows 通过结论 |
| 沉浸与恢复 | 真正留白可进入沉浸，只保留正文、居中书名和页数；移动鼠标、Esc 或词句操作恢复，正文尺寸、分页和位置不变 |
| 取消优先与翻页 | 有选区、菜单或浮层时点击留白先处理已有操作；箭头不显示，方向键、PageUp / PageDown、滚轮可翻页，浮层操作与手柄拖动不误翻页 |
| 进度与导航 | 书架左下角和阅读工具进度随阅读更新；目录与书签标签在同一面板工作，翻页、跳转后进度一致 |
| 书签 | 可保存当前页、从列表跳回和逐条删除，切书与重启后仍按书隔离；字号或主题调整后仍能按内容定位 |
| 阅读设置与主题 | 小 A / 大 A 不显示字号数字；六主题可切换且按书保存，深色主题的正文、工具、导航及单词本清晰可读 |
| API 设置分工 | API 配置仅在书架；阅读设置只含字号与主题，阅读中的错误保留简短状态和回书架引导 |
| 快速收录 | 不等待 API；原拟定反馈目标为 200 毫秒以内，样本测量不代表所有环境保证 |
| 选区与回跳 | 首尾调整、同章节跨页、复制和取消行为正确；能返回正确语境并闪烁 |
| 合并与取消 | 多语境分别保留，日期正确更新，取消不误删其他位置 |
| 短语与释义 | 补全匹配真实原文，不扩展无关文字；解析内容符合上表并贴合语境 |
| 离线、失败与恢复 | 状态可理解；恢复与重试不产生重复词条，100 条任务的书籍、原句和结果关联正确 |
| 界面与数据保持 | 满足界面规范，布局变化不重置书籍、位置、收录和任务 |

后续试用需核对：

- 上述默认规则是否符合实际阅读习惯；具体尺寸、主题近似色值与键盘细节是否需要调整，见 [界面规范](./ui-design.md)。
- 至少两本实际 EPUB 的兼容性，以及预选 20 条内容样本（10 个单词、5 个短语场景、5 个句子，包含跨页句子）的人工释义验收。
- Mac 源码交互试运行、DMG 安装、Keychain 和真实阅读体验的人工验收；正式签名公证构建也尚未运行。现有云端试用包构建与启动检查结果不能替代这些项目。

模拟模型链路与真实模型内容质量分别验收。本轮实际完成的检查只写入 [0.4.0-dev.1 验证报告](./verification/0.4.0-dev.1.md)；旧版的真实 API 和人工验收范围见 [0.2.0 历史报告](./verification/0.2.0.md)，不得根据模拟响应测试推定真实释义已通过。
