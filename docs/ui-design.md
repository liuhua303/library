# 界面与交互规范

适用版本：`codex/japanese-support` 分支 0.5.0-dev.1 当前界面规范，尚未合并进 `main`；本轮 Windows 自动检查和试用包已完成，Mac 检查待运行。`main` 保留 0.4.0-dev.1。更新日期：2026-11-28。

本文维护当前界面的视觉、布局及交互细节。产品功能与范围见[需求](./requirements.md)，开发与代码结构见[开发说明](./development.md)。历史改版背景和执行提示词保留在[视觉改版原稿](./archive/visual-redesign.md)。

## 状态与依据

- **需求确认**：沿用书架、书签、六主题、J 快捷键、沉浸阅读及单词本跟随主题的要求；本轮用户确认日语适配流程与分支开发。语言选择、读音展示等实现仍需试用，具体控件、色值与尺寸不因此改记为用户已逐项验收。
- **实现基线**：具体尺寸、色值和键盘默认值随代码校准；它们不等同于用户曾逐项确认。功能是否完成与实际验证结果分别记录，不将本规范当作测试通过证明。
- **验证范围**：本轮旧书修复已进行 Windows 自动检查，实际结果见 [0.5.0-dev.1 验证报告](./verification/0.5.0-dev.1.md)；上一版日语试用包自动检查见 [0.5.0-dev.0 历史报告](./verification/0.5.0-dev.0.md)，稳定版见 [0.4.0-dev.1 历史报告](./verification/0.4.0-dev.1.md)。规范中的行为与检查目标不代表已经验证通过。

## 视觉原则

- 以阅读正文为主体。原色主题保持白底深色文字；其他主题协调正文、阅读工具、导航及单词本的表面与文字颜色。正文区域不增加装饰卡片、口号或常驻操作教学。
- 临时选区与已收录下划线清楚区分；选区、原文定位反馈及手柄根据主题保持对比度，深色主题不沿用不可见的黑色标记。
- EPUB 封面按原图显示，保留原有颜色，不因阅读主题去色或替换。
- 优先通过留白、细分隔线和轻阴影组织层次。必要的状态、错误和操作入口保持可见。
- 沿用 Lucide 图标体系。图标按钮应有可访问名称，键盘焦点应清楚可见。
- 阅读容器、正文视口和承载正文的 iframe 聚焦时不显示围绕书页的焦点框；保留正常聚焦行为，以及按钮、输入框等实际操作控件的键盘焦点提示。

## 书架

- 启动首先显示书架。点击已有书籍封面后，从该书保存的内容位置续读；未读书从开头进入。
- 使用 EPUB 自带封面，不生成替代插画。通过书脊、纸页边缘、圆角与自然阴影呈现书本质感，封面主体保留原图比例，不裁切重要内容。
- 封面左下角显示 0–100% 的整数阅读进度，按保存进度四舍五入，文字与封面保持对比；这是当前书籍的进度摘要，不新增作者、简介或统计卡片。
- 无封面或图片加载失败时，使用书名占位封面，仍可打开书籍并查看进度。
- 书架工具区提供导入和 API 设置入口。空书架只显示必要的“导入 EPUB”主按钮，API 设置仍可访问。
- 封面显示尺寸随可用空间适配；书本装饰不遮挡主体或覆盖点击操作，不以展示效果声明支持小于应用最小尺寸的窗口。

## 阅读页与工具

- 正文为居中单栏、逐页阅读，左侧不常驻书架列表。顶部保留返回书架和必要书名；选区存在时显示选区摘要及调整操作。
- 底部只保留页数，永久移除左右翻页箭头。使用左右方向键、`PageUp` / `PageDown` 或鼠标滚轮翻页。右下角圆形按钮打开紧凑的阅读工具，包含“目录 · X%”、当前页书签、单词本和阅读设置。
- 工具菜单展开于按钮上方，颜色跟随主题；单词本入口保留 `J` 提示。当前页书签只显示图标，不显示“添加当前页书签 / 本页已添加书签”等常驻解释；保留可访问名称与选中态。
- 阅读设置包含字号、六主题与“书籍语言”；API 密钥和模型字段不出现在阅读工具、阅读设置或单词本内。
- 字号界面仅显示小 A / 大 A 按钮，不显示数值。内部范围仍为 14–34px，每次调整 2px，并按书籍保存；到达边界后相应按钮禁用。
- 修改字号后按内容位置重新定位；打开或关闭单词本不触发这一排版过程。切换主题保留当前阅读内容位置，不重置该书字号或收录。
- 正文容器宽度随窗口及字号调整，当前最大宽度为 `min(1200, max(760, 字号 × 36))px`，同时受可用窗口宽度限制。
- 原稿中“每行约 60–75 个英文字符”是排版校准建议，尚无逐书测量保证；不将它记为已通过的验收指标。
- 本轮不扩展亮度、搜索、分享、高亮标签或自定义布局；功能范围统一按[需求](./requirements.md)维护。

## 日语正文与语言设置

- 阅读设置增加“书籍语言”下拉框，提供“英语 / 日语”，按书保存。保存期间禁用控件，成功后才切换；失败时仍用原语言。切换后已有释义保留，不自动重译。
- 语言来源未确定时提示“未能确定书籍语言，请选择。”；其他情况显示“按书保存，已有释义保留。”。不将暂用英语误显示为已经可靠识别。
- 旧书启动识别及同一文件重导可更新符合条件的语言结果；手动选择受保护，已有位置、字号、主题和释义保留，完整边界见 [旧书语言修正与失败重试](./requirements.md#旧书语言修正与失败重试)。
- 日语正文单击按日语分词定位词语，标点与空白不收录；拖选继续使用既有菜单、手柄与跨页规则。短语补全以该处原文为准，保留活用文字。
- 保留 EPUB 的 ruby 注音显示；日语收录、上下文和标记索引跳过 `rt`、`rp` 注音节点，避免把注音重复当作正文。英文已有定位规则继续保留。
- 日语衬线主题优先使用 Yu Mincho、Hiragino Mincho ProN、Noto Serif JP，醒目与专注主题优先使用 Yu Gothic、Hiragino Kaku Gothic ProN、Noto Sans JP；按系统可用字体回退，界面不要求安装额外字体。单词本的日文词语、例句及原文设置日语语言标记。
- 本轮不增加竖排布局控制。实际竖排书、复杂注音、不同系统字体的显示与选区几何仍待核对，不能根据横排样本推定已支持所有日文排版。

## 点击留白与沉浸

- 阅读区域的留白可进入沉浸；文字、已有标记、选区手柄和操作控件按各自功能处理，不作为进入沉浸的留白。
- 沉浸时隐藏鼠标指针、返回书架、阅读工具及其他操作控件，只保留正文、居中的书名与页数。控件隐藏后保留布局位置，不改变正文尺寸、分页或当前内容位置。
- 移动鼠标恢复指针与控件，`Esc` 退出沉浸；点击单词或开始拖选同样恢复操作，继续原有收录或选择流程。
- 已有临时选区或选词菜单时，点击留白先取消；工具、目录、主题等交互浮层打开时，先关闭浮层。本次点击只处理已有操作，不同时进入沉浸。
- 键盘与滚轮翻页沿用内容位置和选区规则；浮层内部滚动及操作、手柄拖动不翻动背后正文。沉浸开关不增添常驻教学。

## 目录与书签导航

- “目录 · X%”显示当前阅读进度，点击后打开同一个导航面板；面板提供“目录 / 书签”两个标签，不增加高亮标签。
- 目录展示章节并支持跳转；书签列表展示可识别的位置摘要，支持跳转及逐条删除。空书签仅显示简短空态。
- 当前页书签通过阅读工具保存，归属当前书籍；当前页已有书签时，同一入口可移除该书签。列表按书中位置排列，切书、退出和重启后保留。
- 书签保存内容位置，字号或主题变化后仍以内容位置跳转，不将屏幕页号作为唯一锚点；当前页是否已有书签按该页可见内容范围判断。
- 导航及书签按钮的点击、滚动不穿透正文，不造成误收录；删除一条书签不删除单词本或其他书籍的数据。

## 六种阅读主题

| 标识 | 界面名称 | 当前视觉基线 |
| --- | --- | --- |
| `original` | 原色 | 白底深字、衬线正文 |
| `quiet` | 静谧 | 深灰底浅字、衬线正文 |
| `paper` | 纸张 | 浅灰纸色、衬线正文 |
| `bold` | 醒目 | 白底、加粗无衬线正文 |
| `calm` | 舒缓 | 暖纸色、衬线正文 |
| `focus` | 专注 | 浅米色、无衬线正文 |

- 原色为默认白底主题；其余主题按用户提供的参考图校准表面、文字与强调状态。每本书分别保存选择，旧数据缺少主题时使用原色。
- 主题应用于正文 iframe、外层阅读区域、工具、导航和单词本；深色主题中的普通文字、状态、边界、选区、手柄及收录下划线均需可辨认。
- 主题选项显示名称和选中状态，切换主题不引入字体数值、亮度滑杆或自定义布局控件。
- 小 A / 大 A 及主题组织参考 [Apple 图书使用指南](https://support.apple.com/guide/iphone/iphc1af7c57/ios)；六主题的具体视觉来自用户截图。项目使用的色值为近似实现，不声明为 Apple 官方精确色值。

## 单词本浮层

- 单词本覆盖在阅读区域右侧，不占用正文布局宽度；开关时正文容器尺寸、换行、分页、当前位置及已有选区保持不变。
- 单词本限制在可用窗口以内，使用当前主题的不透明面板色，与目录及工具面板保持同色系，保持圆角及独立层次，不增加背景模糊。
- 词句、释义、次要文案、原文标记、边界、悬停、键盘焦点和滚动条均跟随主题；次要文字使用主题的实色弱化文字，保持可辨认的对比。
- 单词本没有全屏遮罩，不使整页正文变暗。书架的 API 设置对话框另有遮罩，二者用途不同。
- 顶部保留“单词本”、必要状态和关闭按钮；内部独立滚动，不穿透操作正文、不带动书页翻页。
- 词句与中文释义优先。折叠词条预览最近语境释义；展开后按语境展示中文释义，英文收录随后显示英文解释，日语词语与短语随后显示带“读音”标签的假名。用法与例句、原文按需展开，日语例句保持日文。
- 整句展示中文翻译及原文，不套用词语的读音、英文解释、用法和例句结构。日期、章节、多语境、返回原文、逐处取消和必要重试仍可访问。
- 从原文选择“查看”时，打开浮层并展开、定位到对应语境；“返回原文”收起浮层，按该次收录位置定位，目标反馈闪烁两次。
- 收录与后台解析完成不自动打开浮层。空单词本显示“暂无收录”；待处理及失败状态使用与主题协调的图标与简短文字，保留必要重试。需要密钥或模型配置时，仅简短提示返回书架设置，不在阅读中打开 API 表单。
- 失败记录保留“重新解析”入口。若其语言与当前书籍不同，用户手动操作后从原位置重建选文、上下文与锚点，再进入当前语言的解析队列；重试期间禁用按钮。原文无法可靠定位时保留失败记录并显示错误。语言修正本身不触发该操作，已完成或正在解析的记录不被改写。

## 选区与标记

- 临时选择使用清晰可见的文字范围及首尾调整手柄；已收录范围使用与主题协调的下划线，二者保持可区分。
- 单击未收录单词后立即显示收录反馈；拖选后通过“复制 / 收录”菜单操作。点击已收录范围显示“查看 / 取消收录”菜单。
- 选区支持两端拖动与“调整起点 / 调整终点”；同章节翻页后可保留选区并继续调整。跨章节边界按[需求](./requirements.md)处理。
- 高亮与手柄以实际文字片段为边界，避免段落容器背景、空白高亮或重复绘制。字号、翻页和短语补全后应重新测量对应范围。
- 有选区或选词菜单时，点击正文留白先取消，本次不进入沉浸；点击词句或开始拖选会恢复操作控件。操作工具、导航、单词本、阅读设置和选区控件时，应保留原有选区，避免焦点变化造成误收录或丢失。

## 键盘、焦点与关闭规则

以下沿用既有键盘默认规则，随本轮导航和阅读设置维护；具体焦点细节不代表用户曾逐项确认：

| 输入或场景 | 当前行为 |
| --- | --- |
| 正常阅读页按 J | 打开或关闭单词本，同时收起工具与导航；正文 iframe 内同样有效，长按不重复切换。 |
| 阅读设置打开时 | 焦点进入设置控件，Tab 在可用控件内循环，Esc 关闭并返回工具按钮；J 和方向键不触发背后阅读操作。 |
| 输入框、语言下拉框、可编辑区域、输入法组合输入、API 设置打开时 | 不触发阅读快捷键；Ctrl / Alt / Meta 组合键也不触发。 |
| 阅读页按 Esc | 沉浸时先恢复指针和控件；其他状态优先收起工具、导航或阅读设置，再关闭单词本，均未打开时清除临时选区。不解释为取消收录或删除书签。 |
| 左右方向键、PageUp / PageDown | 在阅读区域翻页；操作单词本、工具、导航、选区控件和阅读设置时不翻动背后正文，手柄拖动时也不翻页。 |
| 鼠标滚轮 | 在阅读区域向下翻后页、向上翻前页；浮层内部滚动及手柄拖动时不翻动背后正文。 |
| 有交互浮层时点击阅读留白 | 先关闭相应浮层，本次不进入沉浸。 |
| 打开单词本 | 焦点进入关闭按钮。关闭后焦点回到正文 iframe，无法取得时回到阅读容器。 |
| 打开书架 API 设置 | 焦点进入输入框，Tab 在对话框内循环，Esc 关闭；关闭后恢复原触发控件焦点。 |

## 视觉参数

下表保留稳定参数及维护依据。主题色值与浮层尺寸以当前主题样式为准，不将每个值描述为独立的用户确认要求。

| 项目 | 当前实现 |
| --- | --- |
| 默认主题背景与表面 | 白底；其他主题采用相应表面颜色 |
| 文字、图标、收录下划线 | 跟随主题前景色；下划线为 2px |
| 临时选区与原文定位反馈 | 跟随主题保持对比度；原色沿用淡蓝色项目色值 |
| 界面字体 | Segoe UI / Microsoft YaHei UI / Microsoft YaHei / sans-serif |
| EPUB 正文字体 | 英文原色、静谧、纸张、舒缓为 Georgia / Times New Roman / serif；醒目、专注使用系统无衬线字体，醒目加粗。日语采用上文日文字体回退；行高 1.75 |
| 主要控件字号 | 常用 14–16px；必要的日期、标签等次要信息约 12–14px |
| 阅读工具 | 圆形触发按钮、圆角浮层；不以悬停作为唯一入口 |
| 状态与层次 | 与主题协调的分隔线、阴影和状态图标，避免多余装饰 |
| 动效 | 单词本短暂移入，原文定位反馈闪烁；响应系统减少动画设置 |

## 维护时的验收要点

这些是后续修改需要检查的场景，实际通过范围和测量结果只写入对应版本的验证报告。

| 场景 | 检查内容 |
| --- | --- |
| 启动、书架与续读 | 真实封面及书本质感不遮挡内容，左下进度可读；无封面仍可打开，续读、切书和重启后数据保留。 |
| 正常阅读与工具 | 默认白底阅读，主题色与文字协调、单栏版心，必要工具可发现；关闭工具后正文简洁。 |
| 沉浸与恢复 | 留白进入后仅正文、居中书名和页数可见；指针与控件按默认规则恢复，布局、分页、内容位置不变。 |
| 留白优先级与翻页 | 选区、菜单或浮层先取消/关闭；两种阅读状态均无底部箭头，方向键、PageUp / PageDown 和滚轮翻页可用，浮层与手柄操作不误翻页。 |
| 导航与书签 | “目录 · X%”与书架进度一致；同一面板的两标签可用，书签保存、跳转、删除和重启保留正确。 |
