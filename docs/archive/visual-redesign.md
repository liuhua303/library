# 阅间：视觉改版设计约定

日期：2026-11-26。状态：用户已确认方向并明确要求开始实施；本文件作为本次视觉改版的设计依据。

本轮目标是让阅读成为界面的主体。保留现有功能、数据和后台处理流程；启动先到书架、J 快捷键和单词本浮层是用户本轮明确提出的调整。本文件中标为“已确认”的内容来自用户选择；标为“建议”的尺寸和交互细节不视为已获逐项确认。

## 1. 当前体验需要解决的问题

| 当前表现 | 对阅读的影响 | 改版方向 |
| --- | --- | --- |
| 阅读时左侧书架长期占位，顶部标题和工具区分层占用空间 | 正文可用面积减少，界面比书页更抢眼 | 独立书架入口，阅读时移除常驻书架，合并并收纳工具 |
| 大窗口正文行长缺少约束 | 横向扫读距离过长 | 使用居中的单栏版心，按字号校准行长 |
| 单词本先展示较长原文和元数据，中文释义靠后 | 回看时难以迅速找到核心含义 | 词句与中文释义优先，其余信息按需展开 |
| 口号、装饰英文、重复标题和操作说明较多 | 增加与正文无关的视觉负担 | 删除说明性装饰，保留功能名称和必要状态 |

## 2. 用户已确认的设计要求

### 整体风格

- 极简，以阅读为中心；应用背景为纯白，文字与按钮为黑色。
- 临时选区可以使用类似苹果阅读的淡蓝色。此颜色服务于选中状态，不作为全局强调色。
- 单词本采用相同的极简风格。
- 参考用户提供的苹果图书截图中的工具分组、圆角浮层和按需展开方式。
- 删除解释性小字、装饰英文、口号和常驻操作教学。

### 启动与书架

- 每次启动首先显示书架。
- 书架直接展示导入 EPUB 自带的书皮封面图片，使用书中实际封面，不另行设计或生成替代封面；封面外不增加作者、简介、进度条或阅读统计卡片。
- 封面按原图显示；黑白约束用于应用界面。
- 点击封面，进入该书上次保存的阅读内容位置；未读书从开头进入。
- 此要求替代旧版启动后直接打开上次阅读书籍的行为，不改变阅读位置的保存规则。

### 阅读与工具

- 单词本入口放在阅读工具区，通过键盘 J 快速打开和关闭。
- 用户选择了“浮层查阅”：单词本在右侧覆盖展开。
- 打开或关闭单词本不缩窄正文容器、不重新分页、不改变当前阅读内容位置。
- 单词本由用户主动查看；收录或解析完成时均不自动展开。

## 3. 代表页面与版式建议

代表页面为“正常阅读”，附带工具展开、单词本浮层展开、词句选中三个状态。以下为基于已确认方向的建议，具体尺寸可在后续实现时校准。

### 正常阅读

- 白色书页占据主区域，正文单栏居中；左侧不常驻书架列表。
- 顶部只保留轻量的返回书架入口与必要书名，避免大标题和重复章节栏。
- 底部保留简洁页码与翻页入口，阅读工具收在右下角的黑色圆形按钮中。
- 正文宽度建议以约 60–75 个英文字符的行长为校准起点，同时适配用户原有字号；不以固定像素强行限制大字号阅读。
- 保持现有字号及其保存行为，不重置用户已有阅读设置。

### 阅读工具

- 点击工具按钮后，在按钮上方展开紧凑的白色圆角菜单，使用黑字与黑色图标。
- 仅组织现有的目录、字号和单词本入口，提供返回书架与设置的可发现入口。
- 将字号操作放在同一组；单词本菜单项显示 J 提示，避免在正文区域放快捷键教学。
- 不照搬参考图中的主题切换、亮度、搜索、书签、分享等额外功能。
- 避免将触发按钮完全依赖悬停；鼠标和键盘均能操作。

### 单词本浮层

- 建议宽度 360–400px，窄窗口下限制在可用宽度以内；覆盖正文右侧，正文的布局尺寸始终不变。
- 使用不透明白底，黑字；以留白和少量细分隔线组织词条，取消层层包裹的卡片。
- 顶部保留“单词本”和关闭入口，不再重复英文装饰标题、整书名称和完成庆祝文案。
- 中文释义紧跟词句。英文解释、用法、例句、原句、章节、收录日期和多处语境仍可查看，不因极简而删除。
- 句子的解析内容只需原句及中文翻译，不套用单词的完整解析结构；日期、章节、原文回跳和取消收录等元数据与操作仍保留。
- 原文回跳、逐处取消收录及必要重试操作仍可发现。
- 浮层内部滚动不翻动书页；浮层操作不穿透到正文。
- 建议无全屏遮罩，不将整页正文变暗；关闭浮层后立即恢复完整阅读视野。
- 建议从单词本返回原文时自动收起浮层，让目标位置完整可见，并保留已有的两次闪烁反馈。

### 书架与空状态

- 封面采用统一高度的疏朗网格，保留原有宽高比，不裁掉重要封面内容。
- 导入与设置收在简洁工具区，避免大面积欢迎页和使用教程。
- 没有书籍时，空态正文只提供“导入 EPUB”等必要入口，工具区仍保留设置；空单词本只显示“暂无收录”等简短状态。
- 无封面书籍建议使用白底黑字的书名占位封面；标题属于占位封面内容，不额外增加封面下方说明。

## 4. 设计系统建议

| 项目 | 约定 |
| --- | --- |
| 平台 | Windows 桌面应用，沿用 Electron / React 现有结构 |
| 背景与浮层表面 | 纯白 `#FFFFFF` |
| 文字、图标、收录下划线 | 黑色 `#000000` |
| 主按钮 | 黑底白色图标或白字；次要操作使用白底黑色图标或黑字 |
| 临时选区 | 建议淡蓝 `#D8EAFE`；为本项目候选值，并非声称苹果使用此精确色值 |
| 分隔与层次 | 优先留白；必要细线和轻阴影只使用黑色的低透明度，不增加彩色状态色 |
| 字体 | 正文建议沿用 Georgia / Times New Roman 衬线字体；界面使用 Segoe UI / Microsoft YaHei 系统字体 |
| 界面字号 | 主要控件约 14–16px，必要次要信息约 12–14px，避免低对比度小字 |
| 间距 | 建议以 8px 为基础，组合 12 / 16 / 24 / 32px 等间距 |
| 圆角 | 工具菜单与浮层建议 20–24px；图标主按钮为圆形；正文不套卡片 |
| 图标 | 沿用项目现有 Lucide 图标体系，黑色、统一线宽 |
| 动效 | 建议只给浮层短暂出入场动效，尊重减少动画设置；不改变正文位置 |

封面直接使用 EPUB 自带图片，按原图显示。应用控件采用黑白，临时选区使用淡蓝色。

## 5. 现有功能与流程保护约束

1. 单击未收录单词立即收录并留下简单下划线，不等待模型，不弹出释义。
2. 拖选词句仍需从小菜单选择复制或收录；首尾可调整，同章节跨页后能继续调整终点；点击空白处可取消。
3. 临时淡蓝选区、首尾手柄与已收录的黑色下划线清楚区分。保留已完成的跨段文字几何去重，避免整段文字染色、重复高亮或空白高亮回归。
4. 点击已收录词句，保留“查看 / 取消收录”菜单。“查看”打开右侧浮层，在正确词条和语境处定位并展开。
5. 单词本返回原文仍使用该次收录的内容位置定位，目标闪烁两次；字号改变后的定位仍有效。
6. 每书独立单词本、同词合并、多处语境和分别解析、最近收录日期更新、逐处取消规则全部保留。
7. 短语识别与补全仍在后台进行，可靠匹配后下划线扩展到完整短语。
8. 离线收录、等待解析、恢复任务、失败与重试流程不变。相关状态用黑白图标和简短文字表达，放在对应条目或设置中。
9. 删除“解析会在后台完成”等常驻教学，不删除用户需要处理的错误、状态和操作。
10. 返回书架、切换书籍和重启均保留用户数据、阅读位置、标记与任务。通过正文内容位置续读，不依赖随字号变化的屏幕页号。

## 6. 建议的交互默认规则

以下是实现建议，尚未逐项确认：

- J 仅在阅读页切换单词本；输入框、可编辑区域、输入法组合输入和设置对话框内不触发，Ctrl / Alt / Meta 组合键也不触发。
- 键盘焦点位于 EPUB 正文内时，J 同样有效；关闭浮层后焦点回到阅读区域或原触发控件。
- Esc 可关闭当前最上层菜单或浮层；不将按 Esc 解释为取消收录。
- 点击工具外部关闭工具菜单；单词本默认通过关闭按钮或 J 关闭，避免仅为收起面板的点击误触正文收录。
- 正在操作浮层时，正文选区和收录标记保留，不因焦点变化自行丢失。
- 浮层宽度、工具位置和字体排版先用上述建议作为校准起点，不引入布局切换设置或新的个性化配置页。

## 7. 视觉改版验收建议

| 场景 | 通过标准 |
| --- | --- |
| 启动与续读 | 软件先显示封面书架；点击已读书籍后进入保存的内容位置 |
| 正常阅读 | 白底黑字，单栏版心，无常驻左书架、口号、装饰英文和操作教学 |
| 工具收纳 | 目录、字号、单词本等现有入口仍可发现，关闭菜单后正文区域简洁 |
| 浮层与 J | 打开、关闭和连续切换均不改变正文容器宽高、不触发重新分页；原内容位置、行换行和选区不变 |
| 单词本 | 中文释义优先，其余解析、原文、日期、多语境和必要操作均能查看；整句只提供中文翻译 |
| 定位 | 原文查看能定位正确语境；返回原文后目标可见并闪烁两次 |
| 标注 | 单词、短语、跨行、跨段、跨页选择和两端调整无重复标记、漏画或整段染色 |
| 失败状态 | 未配置、等待、解析中和失败有简短可理解的状态及对应入口，不强行弹窗 |
| 窗口与键盘 | 在应用支持的窗口尺寸和字号下，工具及浮层不越界；键盘焦点可见，输入密钥时 J 不误触发 |
| 数据保持 | 用户现有书籍、收录、释义、阅读位置和任务保留，不因视觉改版重置 |

这些标准用于后续实现与检查，不代表本轮已实现或已通过测试。

## 附录：具体改版提示词

以下提示词按 [Google Labs enhance-prompt 上游技能](https://github.com/google-labs-code/stitch-skills/blob/main/plugins/stitch-utilities/skills/enhance-prompt/SKILL.md)的结构整理，作为本次已授权改版的执行依据。

为现有 Windows 英语阅读器“阅间”进行极简视觉改版，让书页正文成为界面主体，依据本文件完成现有项目的界面调整。

### DESIGN SYSTEM (REQUIRED)

以本文件第 2 节的已确认要求和第 4 节的设计系统为依据。第 3、4、6 节中的具体尺寸、字体和交互默认值属于设计建议，可据实际页面校准。沿用项目现有 Electron、React、TypeScript、EPUB.js 及 Lucide 图标体系。

### Page Structure

1. **启动书架：**按第 2、3 节展示导入 EPUB 自带的真实封面，点击后续读；保留导入与设置入口。
2. **正常阅读：**以居中单栏正文为主体，收纳工具，保留轻量导航与翻页；作为先完成的代表页面。
3. **工具展开：**按第 3 节组织目录、字号、单词本等现有入口。
4. **单词本浮层：**从右侧覆盖展开，J 切换，正文尺寸与分页不变；中文释义优先，其余内容和操作按正文约定保留。
5. **选区与菜单：**临时选区淡蓝，已收录内容用黑色下划线；保持现有选中、调整、收录、查看和取消操作。

### 行为与交付约束

完整遵守第 5 节的功能与数据保护约束，按第 6 节校准交互默认规则，以第 7 节验收。先完成代表阅读页的正常、工具展开、单词本浮层和跨行选中状态，再应用到书架、设置与必要状态。

在现有项目上修改，保留真实书籍和业务数据，不用示意封面或模拟解析替换现有内容。使用隔离测试数据，不读取真实密钥或触发真实模型费用。汇报实际改动、验证结果和仍待调整的细节。
