# 英语阅读器首版需求与方案确认稿

面向个人使用的 Windows 英语阅读器，核心目标是减少查词对阅读的打断：阅读时快速收录词句，后台结合原文生成解析，由用户自主决定何时查看。需求与技术方案依据截至 2026 年 11 月 26 日的讨论整理。

视觉改版补充见 [DESIGN.md](./visual-redesign.md)：用户已确认启动先到封面书架，点击书籍续读；右侧单词本采用覆盖式浮层，通过工具区或 J 开关，浮层开关不改变正文排版与当前位置。其余功能和后台流程沿用本文。

**已确认需求和已选技术方案**列于前五节；**首版边界、默认规则和验收标准建议**列于后续章节。用户已于 2026 年 11 月 26 日明确要求开始开发；尚未单独确认的默认规则先作为初始实现基线，保留调整空间。

## 已确认的目标和使用范围

用户具有一定英语基础，主要困难是生词较多、单词可能属于短语，以及偶尔无法理解整句。解析需要结合书籍上下文，减少选词、等待和查看释义对阅读的打断。

- 首版供个人使用，提供可安装并从桌面打开的 Windows 软件。
- 首版只支持 EPUB；用户现有的本地 EPUB 文件作为后续兼容性样本。
- 采用逐页翻页，支持目录跳转、自动记住阅读位置和调整字号。
- 不需要切换背景。
- 每本书拥有独立单词本，书籍、阅读进度、单词本和任务保存在本机。
- 允许将收录词句及必要的附近原文发送给用户提供密钥的 DeepSeek API。
- 预计每天收录约 100 条词句，这是初步工作量估计。

## 已确认的阅读和收录操作

| 操作 | 预期行为 |
| --- | --- |
| 单击未收录的单词 | 默认立即收录，原文显示简单下划线，不自动展示解析。 |
| 拖选单词或句子 | 出现“复制 / 收录”小菜单，选择“收录”后才入库并显示下划线。 |
| 调整选区 | 可以拖动首尾两端调整范围；翻页后保留选区，并能继续调整终点。 |
| 取消选中 | 点击空白处取消选区，不产生收录。 |
| 自动识别短语 | agent 识别出所选词所属的完整短语后，补全短语及含义，并把原文下划线扩展至完整短语。 |
| 点击已收录的词句 | 弹出包含“查看”和“取消收录”的小菜单，选择“取消收录”才移除。 |
| 点击“查看” | 在右侧单词本中定位并展开对应解析。 |
| 从单词本返回原文 | 跳到该次收录所在位置，对应标记简单闪烁两下。 |

右侧单词本由用户主动打开，展开时书页仍然可见。收录与解析完成均不自动弹出解释。

## 已确认的单词本与解析

每本书的单词本独立存储。一个词在同一本书中被多次收录时，合并在一个词条下，保留各处原句及对应解析，收录日期更新为最近一次收录的时间。不同书籍之间不合并词条。

| 收录内容 | 解析要求 |
| --- | --- |
| 单词和短语 | 以原文语境中的中文释义为重点，同时提供英文解释、用法说明和例句。 |
| 整句 | 提供中文翻译即可。 |

同一词的不同语境需要分别保留对应含义，避免用一处释义覆盖所有原句。

## 已确认的数据和后台行为

离线时可以继续阅读和收录，联网后处理未完成任务。关闭阅读器后可以暂停处理，下一次打开时继续。

- 单词本显示等待联网、待解析、解析中、失败等状态，完成后自动更新为解析内容。
- 失败时提供重试入口，等待与失败状态不通过弹窗打断阅读。
- 首版每条语境用一次完整的模型回答生成所需解析；不增加自主词典查询、联网搜索或额外的模型审查流程。
- 本机后台负责任务保存、上下文提取、请求执行、返回格式校验和结果保存。

“下次打开继续”表示恢复待处理任务；中断的模型请求可以重新发起，不要求恢复模型生成到一半的内部状态。

## 已选定的技术方案

| 部分 | 已选方案 | 作用 |
| --- | --- | --- |
| Windows 软件 | Electron | 提供可安装的桌面应用及本机后台。 |
| 用户界面 | React 与 TypeScript | 实现阅读区、右侧单词本、选区菜单及交互状态。 |
| EPUB 阅读 | EPUB.js 与定制交互 | 提供阅读和定位基础，定制点击取词、跨页选区、调整手柄和下划线。 |
| 本机数据 | SQLite | 保存书籍信息、阅读位置、词条、收录语境与任务。 |
| 后台解析 | 本机持久任务队列与 DeepSeek API | 先保存收录，再独立解析，重启后恢复任务。 |

Electron 随应用提供 Chromium 与 Node.js；SQLite 直接读写本机数据库文件，无需另设数据库服务器。[Electron 官方说明](https://www.electronjs.org/docs/latest/)、[SQLite 官方说明](https://www.sqlite.org/serverless.html)

EPUB.js 提供分页、选区与原文定位等基础。跨页选区保持、首尾调整手柄和短语标记扩展需要定制，是进入开发后的优先验证项。[EPUB.js 官方文档](https://github.com/futurepress/epub.js/blob/master/documentation/md/API.md)

实现时以内容位置标识和原文片段保存定位，字号改变后重新定位至当前排版中的对应页面。本轮视觉改版中，单词本覆盖正文，开关时不改变阅读容器尺寸或触发重新分页。API 密钥由用户在本机配置，交由本机后台使用 Windows 系统提供的加密能力保护。[Electron 本机加密说明](https://www.electronjs.org/docs/latest/api/safe-storage)

## 首版边界与默认规则建议

以下规则尚待用户确认：

1. **书籍兼容范围**：以普通、正文未受 DRM 保护、可随字号重新排版的 EPUB 为首版目标；暂不支持固定版式 EPUB。来源网站和能否导入苹果图书均不作为兼容保证，以实际文件验收。字体混淆与正文 DRM 保护应区分判断。[EPUB 标准](https://www.w3.org/TR/epub-33/#sec-container-metainf-encryption.xml)
2. **跨页选区边界**：支持同一章节内跨页保留选区并调整两端；跨章节的连续选区暂不纳入首版。
3. **取消一处收录**：只移除该处标记、语境和关联待处理任务；其他收录位置保留。最后一处取消后，才移除整个词条。已取消记录的后台结果不得让它重新出现。
4. **词条归并**：按同一词或完整短语归并，忽略字母大小写；暂不做词形还原或同义词合并。短语作为独立学习对象，与单独使用的单词分开。
5. **短语定位**：只有补全短语能可靠匹配到该处真实原文时才扩大下划线；匹配失败时保留原标记，并允许从单词本重试。
6. **单词本呈现**：按最近收录时间倒序排列；每个语境显示原句与对应解析，单词或短语先提供一个例句。
7. **请求策略**：优先使用 DeepSeek Flash 非思考模式；技术失败可有限自动重试。密钥错误或余额不足等待用户处理，避免持续重复请求。格式与定位检查由本机完成，不额外增加模型回答轮次。
8. **辅助功能范围**：提供满足导入和切换书籍的简单书架；背词计划、测验、云同步、其他文件格式和多端应用暂不纳入首版。

## 验收标准建议

建议在用户实际使用的 Windows 电脑上，以至少两本实际 EPUB 验收。预先选定 20 条内容样本，包括 10 个单词、5 个短语场景和 5 个句子，其中包含跨页句子。

| 验收项 | 通过标准 |
| --- | --- |
| 基础阅读 | 样本书可导入、逐页阅读、通过目录跳转并调整字号；重新打开能回到保存的内容位置。 |
| 快速收录 | 正常阅读状态下，单击或确认收录后的下划线反馈目标为 200 毫秒以内，不等待 API；后台解析时仍能继续翻页和选词。 |
| 拖选与跨页 | 首尾均可调整；翻页后选区不丢失，可继续调整终点；复制和点击空白不会误收录。 |
| 短语补全 | 预选短语样本能识别完整短语，准确扩展原文下划线；不扩展到无关文字，不自动弹出解释。 |
| 查看与回跳 | 原文菜单能在右侧展开正确条目；从各条原句跳回对应位置，标记闪烁两下。字号变化和侧栏展开后仍能定位。 |
| 合并与取消 | 重复词归为一条，语境与解析分别保留，日期正确更新；按已确认的取消规则处理，不误删其他位置。 |
| 解析内容 | 单词和短语具备四类内容，整句有中文翻译；20 条预选样本均由用户确认核心语境含义正确，以内容质量验收。 |
| 离线和恢复 | 断网可读、可收录；恢复联网及重新打开后继续任务。阅读位置、词条、标记和已完成解析保留。 |
| 失败处理与规模 | 模拟网络失败、密钥错误和余额不足时，在单词本显示可理解状态；重试后不产生重复词条。处理 100 条任务时，书籍、原句和结果关联正确。 |

这些是拟定的验收要求，不是已经测得的性能或质量结果。

## API 费用估算

按每日约 100 条、每月 30 天，每条输入约 1,000 token、输出约 800 token 估算，月用量约为 300 万输入 token 与 240 万输出 token。按 2026 年 11 月 26 日 DeepSeek Flash 官方价格，不计缓存优惠，计算约为每月 1.89 至 3.78 美元，讨论中按约 2 至 4 美元理解，用户已接受这一量级。实际费用随输入、输出、调用时段及重试次数变化。[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

DeepSeek 的 JSON 输出可用于固定字段解析，仍需检查空内容、截断和字段完整性。[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)
