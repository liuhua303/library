## 本轮新增覆盖

- **书签持久化与旧数据兼容**：旧数据库可以增加书签表，旧书没有主题字段时继续使用原色；书签按书隔离，相同内容位置去重，删除不影响单词本和后台任务。
- **主题保存竞态**：立即显示用户选择，保存失败回退有效基线；连续两次失败、旧成功晚于新失败、旧成功晚于新成功，以及迟到书架快照均有回归覆盖。
- **阅读设置分工**：设置面板只有关闭、小 A / 大 A 和六个主题按钮，没有 API、模型字段或字号数字；书架仍能打开 API 设置。阅读设置中 J 和方向键不操作背后正文。
- **六主题实际渲染**：检查 EPUB 的 html、body、段落和行内文字，覆盖原书颜色、背景、字体及文字填充的 `!important`；醒目主题字重为 600，切换回其他主题后恢复原字重。深色主题正文与下划线可见。
- **导航与位置**：目录和书签两标签可切换，添加当前页书签后状态改变；列表可跳转和删除，改变字号后仍回到保存的内容位置。摘录在标题与段落之间保留空格，不修改正文 DOM 或内容定位。
- **进度与恢复**：测试中目录入口和书架均显示真实保存进度 3%；书架进度位于封面左下。另一书保持独立主题、字号和空书签；重启后偏好与书签保留，删除后再次重启不复现。

## 打包命令与交付

从项目根目录执行：

```powershell
npm run build
node node_modules/electron-builder/cli.js --win nsis --x64 --config.electronDist=node_modules/electron/dist --config.directories.output=release/0.3.0
node scripts/reading-preferences-smoke.mjs "release/0.3.0/win-unpacked/阅间.exe"
```

- 安装包原始输出：`release/0.3.0/Yuejian-Setup-0.3.0.exe`。
- 同内容副本：`release/Yuejian-Setup-0.3.0.exe`。
- 已解包程序：`release/0.3.0/win-unpacked/阅间.exe`，需保留同目录运行文件。
