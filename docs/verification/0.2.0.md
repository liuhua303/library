## 最终验证结果

- `npm test` 共 56 项通过：包含 18 项 EPUB 封面提取测试，以及 3 项迟到书架快照和保存响应的续读、字号回退回归。
- `npm run build` 通过；TypeScript 检查及生产资源构建完成。
- 0.2.0 Windows 安装包生成完成；打包后的程序使用独立测试数据目录启动，书架、数据库与设置读取检查通过。
- `npm run test:e2e` 五套桌面回归全部通过，涵盖基础阅读、鼠标交互、正文颜色、跨段选区和本次视觉改版。
- 启动先显示书架；实际 EPUB 封面图片字节、显示比例和无滤镜状态验证通过；无封面占位、点击续读、切书与重启数据保留通过。
- 只读核对已有两本 EPUB 的封面提取，返回 JPEG 与各自书籍内的实际封面字节一致；未读取用户密钥、设置或数据库，未修改用户数据。
- J 在宿主页面和 EPUB 正文中均只切换一次；设置输入框内 J 正常输入，方向键不翻动背后书页。
- 单词本开关前后，阅读容器尺寸、首 25 个词的文字矩形、内容位置及页码一致；选区不丢失，浮层操作不会误收录。
- 从原文查看对应解析、返回原文收起浮层并闪烁两次通过；最小窗口 1050 × 680 下浮层未越界。
- 返回书架后立即重开同一本书，稳定后的页码与内容位置均不回退；迟到快照及写响应另有可控时序测试。
- 跨行、跨段、两端调整、字号变化及同章节跨页选择检查通过，矩形重叠、多画和漏画面积均为零；两章 8 页 216 个文本片段的黑色正文检查通过。
- 本机自编样本的一次点击到下划线出现测得约 2.5 毫秒，仅作为该次样本的测量值。

以上均在独立临时目录中进行，模型链路使用模拟响应，未读取真实用户密钥或触发真实模型费用。
