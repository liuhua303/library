单元检查还覆盖语言元数据和正文探测、误标及混排、旧数据库幂等迁移、已有解析与排队任务语言快照、英日词条隔离、原文活用及位置校验，并通过英文提示词指纹和请求结构检查确认原英文路径保持。语言保存失败不会被后续位置写入或关闭重试偷偷应用。

本轮调试修正了日语词尾 caret 边界命中，并将新增脚本的异步 IPC 等待改为显式轮询已完成的数据，避免把 Promise 本身当成条件已满足。最终结果为重新运行所得，不把调试失败结果作为通过证据。
