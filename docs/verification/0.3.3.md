# 0.3.3 验证记录

## 原因与修复

上一版为键盘翻页与纯阅读主动聚焦正文容器。在浏览器的键盘焦点模式下，容器匹配 `:focus-visible`，触发默认黑色轮廓。修复前实际测得：正文容器 `outline-style: auto`、宽 1px、黑色，而四周实际边框均为 0。

本次仅针对阅读区、正文视口和承载正文的 iframe 移除焦点轮廓，保留焦点切换、键盘翻页，以及按钮和输入框的可见焦点提示。未修改书籍文件或用户数据。

## 实际验证

验证日期：2026-11-27，Asia/Shanghai（UTC+8）。环境：Windows x64、Node.js 24.12.0、Electron 45.5.0。仓库尚无提交，相关文件和最终应用包的校验值见[运行清单](./evidence/0.3.3/2026-11-27/run-info.json)。

- `npm run build` 通过，包括 TypeScript 检查和生产构建。
- 最终打包的 0.3.3 程序通过扩展后的沉浸阅读回归，10 组检查通过，无页面错误；应用版本和运行时实际应用版本均为 0.3.3。
- 使用真实 Tab 切入键盘模式后聚焦阅读区与正文视口，确认它们确实匹配 `:focus-visible`，但均无边框或可绘制轮廓；iframe 实际获焦时同样无框。
- 进入纯阅读、鼠标移动恢复、Esc 恢复，以及 J 关闭单词本后回到正文 iframe，均保持无框，正文布局、页码和内容位置不变。
- 第二本自编 EPUB 及返回书架后重开，在键盘焦点模式下均无框。
- 阅读工具按钮和书架 API 输入框仍匹配 `:focus-visible`，保留 2px 可见焦点提示。
- 原沉浸场景、选词、真实拖选、滚轮与键盘翻页、单词本滚动隔离均通过。

本轮为定点 CSS 修复，未重新运行其他六套桌面脚本或全量单元测试；[0.3.2 完整验证](./0.3.2.md)保留为历史结果。所有检查使用独立临时数据目录及自编书籍，未读取真实书架或密钥，未调用付费模型。
